# StarDist Biomedical Segmentation Baseline

This repository contains a StarDist-based biomedical image segmentation baseline developed as part of my PhD research preparation and experimentation in medical/biomedical image analysis.

The project is organized into modules for dataset handling, preprocessing transforms, model/inference workflows, evaluation, and utility functions. It is intended to demonstrate my experience with biomedical image segmentation pipelines, Python project organization, and baseline model experimentation.

This public version does not include restricted laboratory datasets, private model weights, patient data, or unpublished lab-specific results.
